# RAW — external sources, pointers only

Store original evidence **outside** this template in your own governed storage (Drive, institutional repository, local versioned archive, etc.). This folder contains a register of source pointers and unresolved provenance, **not** originals, binary duplicates, full manuscripts, correspondence, private files or credentials.

A folder URL can help navigation, but is not an exact file ID or immutable revision. Missing facts should be recorded as `UNKNOWN / NOT YET LINKED`, never inferred from filenames or modification dates.
